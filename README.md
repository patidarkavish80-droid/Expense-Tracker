# Expense Tracker

A Java-based console application to record daily expenses, view expense records, and calculate total spending.

## About the Project

Expense Tracker is a beginner-to-intermediate Java project designed to help users manage and track their daily expenses. It is being developed step by step while practising Core Java and software development fundamentals.

## Planned Features

- Add a new expense
- View all recorded expenses
- Calculate total spending
- Validate user input
- Save expense records to a file
- Interactive console menu

## Technologies Used

- Java
- Maven
- IntelliJ IDEA
- Git and GitHub

## Project Status

**In Development** — Features are being added and tested incrementally.

## Learning Goals

- Strengthen Core Java concepts
- Practise object-oriented programming
- Learn file handling and input validation
- Use Git and GitHub for version control

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK 26 is configured.
4. Run the `ExpenseTracker` main class.
